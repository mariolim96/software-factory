# Progetto

Note sul progetto per gli agenti della factory. Ogni agente legge questo file prima di
lavorare. Scrivi qui ciò che non si ricava dal codice:

- dove sono la documentazione funzionale e quella tecnica (percorsi nel repo o nei riferimenti);
- le convenzioni del team che il builder deve seguire;
- le aree delicate, dove il triage deve alzare il rischio;
- che cosa vede il front-end (API REST, chiamate RPC, viste) e come si scrive il contratto API.
